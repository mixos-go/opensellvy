# Shopee OpenAPI Guide

Use this skill to answer exact Shopee Open Platform API structure questions and
avoid guessing fields.

## Coverage

- Platform: Shopee Open Platform (`open.shopee.com`)
- Version prefix: `v2.<category>.<api_name>` (e.g. `v2.ams.get_open_campaign_added_product`)
- 29 category folders under `references/api/` (AMS, Product, Logistics, Order,
  GlobalProduct, etc.), 444 API docs total.
- Each doc has YAML frontmatter (`category`, `api_name`, `url`, `date_saved`) plus
  structured sections: `**Category:**`, `**API:**`, `**Method:**`, `**HTTP Path:**`,
  parameter tables, and per-language fenced code examples.

## Workflow

1. Read the request and identify the business capability and any explicit method/path/version.
2. Map the capability to a Shopee category (e.g. order/list → `Order`, product create → `Product`).
3. Inspect `references/api/<Category>/<api_name>.md` for the matched API.
4. Search `references/api/` by API name, endpoint path, or keyword when the category is unclear.
5. Read the exact `**Method:**`, `**HTTP Path:**`, parameter / request / response tables,
   and error-code sections from the matched file.
6. Note the API version (the `v2` + segment in the dotted `api_name` / path) and do not
   silently substitute a nearby operation with a different version.
7. If a schema, policy, deprecation, or newer version is not present in the local
   reference, check the official Shopee Open Platform docs
   (`https://open.shopee.com/documents`) and state the gap/source.
8. Do not invent fields, enum values, required flags, or response shapes that are absent
   from the selected API's official schema.

## References

- `references/api/<Category>/<api_name>.md` — one clean Markdown doc per Shopee API.
- Category folders map to Shopee modules (e.g. `AMS`, `Product`, `Logistics`, `Order`, `GlobalProduct`).

## Update & Provenance

- Local reference is a **static snapshot**. It is regenerated by the toolchain in the
  `updskills` repo (`tools/bulk_render_shopee.py`) which pulls the official module
  manifest from `https://open.shopee.com/opservice/api/v1/doc/module/?version=2` and
  re-renders every page. To get fresher APIs, re-run that tool rather than hand-editing.
- For agent use, prefer the official live docs for anything that may have changed
  since this snapshot (deprecations, new scopes, policy).

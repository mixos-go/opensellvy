**Category:** AMS
**API:** batch_remove_products_open_campaign_setting

**Method:** POST
**HTTP Path:** /api/v2/ams/batch_remove_products_open_campaign_setting

## API Description
Batch update products from Open Campaign for a given list of product IDs

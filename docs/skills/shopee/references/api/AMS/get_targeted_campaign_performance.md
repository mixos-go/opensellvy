**Category:** AMS
**API:** get_targeted_campaign_performance

**Method:** GET
**HTTP Path:** /api/v2/ams/get_targeted_campaign_performance

## API Description

| end_date | string | True | 20250831 | The end_date must be: - Equal to start_date for "Day" period type - Saturday for "Week" period type - The last day of a Month for "Month" period type.

**Category:** ACCOUNT_HEALTH
**API:** get_metric_source_detail

**Method:** GET
**HTTP Path:** /api/v2/account_health/get_metric_source_detail

## API Description
Get the Affected Orders / Relevant Listings / Relevant Violations details of metrics.

## Request Parameters

| Name | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| add_on_deal_name | string | True | add on deal name test | Title of the add on deal |
| start_time | int | True | 1624864213 | The time when add on deal activity start. |
| end_time | int | True | 1625382613 | The time when add on deal activity end |
| promotion_type | int | True | 0 | The type of add on deal：add on discount =0；gift with mini spend=1 |
| purchase_min_spend | float | False | 11.1 | The minimum purchase amount that needs to be met to buy the gift with min.Spend |
| per_gift_num | int | False | 11 | Number of gifts that buyers can get |
| promotion_purchase_limit | int | False | 12 | promotion_purchase_limit |

**Category:** ADS
**API:** create_manual_product_ads

**Method:** POST
**HTTP Path:** /api/v2/ads/create_manual_product_ads

## API Description
Use this API to create Manual Selection Product Ads

Request

## Common Request Parameters

| Name | Type | Sample | Description |
| --- | --- | --- | --- |
| partner_id | int | 1 | Partner ID is assigned upon registration is successful. Required for all requests. |
| timestamp | timestamp | 1610000000 | This is to indicate the timestamp of the request. Required for all requests. Expires in 5 minutes. |
| access_token | string | c09222e3fc40ffb25fc947f738b1abf1 | The token for API access, using to identify your permission to the api. Valid for multiple use and expires in 4 hours. |
| shop_id | int | 600000 | Shopee's unique identifier for a shop. Required param for most APIs. |
| sign | string | e318d3e932719916a9f9ebb57e2011961bd47abfa54a36e040d050d8931596e2 | Signature generated by partner_id, api path, timestamp, access_token, shop_id and partner_key via HMAC-SHA256 hashing algorithm. More details: https://open.shopee.com/documents?module=87&type=2&id=58&version=2 |

## Request Parameters

| Name | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| reference_id | string | True | asdf-1234-qwerty | A random string used to prevent duplicate ads. If an ads is created successfully, subsequent request using the same reference id will fail |
| budget | float | True | 10.50 | The budget set for the Auto Product Ads |
| start_date | string | True | 11-11-2023 | the start date per campaign. please kindly note that if you want to set unlimited date, you can just pass today's date as the start date |
| end_date | string | False |  | the end date of each campaign. please kindly note that if you want to set an unlimited campaign, you can keep empty for the end date field |
| bidding_method | string | True | auto | auto, manual |
| item_id | int64 | True | 111222 | Product ID |
| roas_target | float | False | 1.20 | the ROAS target for each campaign with auto bidding. If 0, GMV Max / ROI feature is not enabled |
| selected_keywords | object[] | False |  | selected keywords, required for manual bidding mode |
| keyword | string | True | apple | bid keyword for each campaign |
| match_type | string | True | exact | exact, broad |
| bid_price_per_click | float | True | 11.20 | the bid price of keyword |
| discovery_ads_locations | object[] | False |  | the location settings for manual bidding method |
| location | string | True | daily_discover | daily_discover, you_may_also_like |
| bid_price | float | True | 10.50 | bid price of the location |
| enhanced_cpc | boolean | False | true | Enhanced CPC functionality toggle |
| smart_creative_setting | string | False | default | Whether to use default or set on/off Smart Creative for this ad. Supported Values: "", "default", "on", "off". Empty string treated as default. |

## Request Parameters

| Name | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| campaign_id | int64 | False | 12412421 | The GMS Campaign ID. Provide if available. |
| edit_action | string | True | change_budget | The following is the list of possible actions and their required fields: 1.change_budgetdaily_budget 2.change_durationstart_date 3.end_date 4.pause 5.resume 6.start 7.change_roas_targetroas_target: when edit_action = change_roas_target, you must provide: roas_target (float) Value rules follow the same logic as in the create endpoint |
| daily_budget | float | False | 100.12 | Daily budget for Campaign. |
| start_date | string | False | 11-11-2025 | Start date of Campaign e.g. "11-11-2025". Cannot be earlier than today. |
| end_date | string | False | 11-11-2025 | End date of Campaign e.g. "11-11-2025". Do not fill if no end date. |
| roas_target | float | False |  | No input will be GMV Max Auto Bidding (Shop). Input 0 for GMV Max Auto Bidding (Shop). Input greater than 0 for GMV Max Custom ROAS (Shop). If value = 10.123456, it will be taken as 10.1 If value = 10.199999, it will be taken as 10.1 |
| reference_id | string | False | 086a16bf-49e9-4103-b7fe-c0125beb9278 | Generated by developers, used to prevent duplicate requests Submitting the same reference_id more than once will fail; a new reference_id must be generated to retry. Example: 086a16bf-49e9-4103-b7fe-c0125beb9278 |

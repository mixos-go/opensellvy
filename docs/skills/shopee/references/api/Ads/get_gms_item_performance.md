**Category:** ADS
**API:** get_gms_item_performance

**Method:** POST
**HTTP Path:** /api/v2/ads/get_gms_item_performance

## API Description
Get GMS Item performance
1. The response returned is sorted by item_id
2. Only items with performance will be returned

Request

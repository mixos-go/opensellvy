**Category:** ADS
**API:** get_product_level_campaign_setting_info

**Method:** GET
**HTTP Path:** /api/v2/ads/get_product_level_campaign_setting_info

## API Description
Call this API to fetch all the campaign setting info under this Shop.

Request

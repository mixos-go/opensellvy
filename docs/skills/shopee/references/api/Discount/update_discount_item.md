**Category:** DISCOUNT
**API:** update_discount_item

**Method:** POST
**HTTP Path:** /api/v2/discount/update_discount_item

## API Description
Use this api to update items of the discount promotion.

Request

## Request Address

| Environment | Location | HTTP Address |
| --- | --- | --- |
| Live | Global | https://partner.shopeemobile.com/api/v2/discount/update_discount_item |

| Live | Brazil | https://openplatform.shopee.com.br/api/v2/discount/update_discount_item |
| Sandbox | Global | https://openplatform.sandbox.test-stable.shopee.sg/api/v2/discount/update_discount_item |
| Sandbox | Chinese Mainland | https://openplatform.sandbox.test-stable.shopee.cn/api/v2/discount/update_discount_item |

## Request Parameters

| Name | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| discount_id | int64 | True | 1000029745 | Shopee's unique identifier for a discount activity. |
| item_list | object[] | True |  | The items selected to this discount. You can update at most 50 items per call. |
| item_id | int64 | True | 1776783 | Shopee's unique identifier for an item. |
| item_promotion_price | float | False | 96.0 | The discount price of the item. |
| model_list | object[] | False |  | The models selected to this discount. |

| purchase_limit | int32 | False | 1 | The max number of this product in the promotion price. |

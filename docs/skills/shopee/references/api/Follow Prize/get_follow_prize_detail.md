## Response Parameters

| Name | Type | Sample | Description |
| --- | --- | --- | --- |
| response | object |  | Detailed informations you are querying. |
| campaign_status | string | ongoing | The status of follow prize,the campagin status have upcoming/ongoing/expired. |
| campaign_id | int32 | 1551 | The unique identifier for the created follow prize. |
| usage_quantity | int32 | 100 | Please enter a value between 1 and 200000. |
| start_time | timestamp | 1655891400 | The timing from when the follow prize is valid,the start time later than the current time.If the start time and end time passed in by the seller overlap with other upcoming/ongoing activities, it will prompt "Another Follow Prize voucher already exists during this time period, please set another period." |
| end_time | timestamp | 1656581220 | The timing until when the follow prize is still valid,the end time must be greater than the start time by at least 1 day and end time cannot exceed 3 months after start time.If the start time and end time passed in by the seller overlap with other upcoming/ongoing activities, it will prompt "Another Follow Prize voucher already exists during this time period, please set another period." |
| min_spend | int32 | 100 | The minimum spend required for using this follow prize. |
| reward_type | int32 | 3 | The reward type of the follow prize.The available values are:1:discount---fix amount,2:discount---by percentage,3:coin cash back. |
| follow_prize_name | string | follow prize01 | The name of the follow prize,The follow prize name length max limit is 20. |
| discount_amount | int32 | 50 | The discount amount set for this particular follow prize.Only fill in when you are creating a fix amount follow prize. |
| percentage | int32 | 1 | The discount percentage set for this particular follow prize. Only fill in when you are creating a discount percentage follow prize or coins cashback follow prize.Discount percentage (reward_type ==2) or Percentage of coins cash back (reward_type==3). |
| max_price | int32 | 20 | The max amount of discount/value a user can enjoy by using this particular follow prize. Only fill in when you are creating a discount percentage follow prize or coins cashback follow prize. |
| error | string |  | Indicate error type if hit error. Empty if no error happened. |
| message | string |  | Indicate error type if hit error. Empty if no error happened. |
| request_id | string | 086501fb756e86e90c754c4ba5d74fe9 | The identifier of the API request for error tracking. |

**Category:** GLOBAL_PRODUCT
**API:** add_global_model

**Method:** POST
**HTTP Path:** /api/v2/global_product/add_global_model

## API Description
Add global model. Only for China mainland sellers and Korean sellers.

Request

## Request Parameters

| Name | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| global_item_id | int64 | True | 37001402 | ID of global item. |
| global_model | object[] | True |  | Global model setting list. Limit is [1,50]. |
| global_model_sku | string | False | sku | Sku of global model. model_sku length information needs to be no more than 100 characters. |
| tier_index | int32[] | True | [1] | Tier index of global model. |
| seller_stock | object[] | False |  | seller_stock of global item |
| location_id | string | False | CNZ | location_id of stock, if the merchant has 3PF shop, the location_id cannot be empty, can use the get_merchant_warehouse_location_list API to obtain the location_id list of the merchant, if the merchant does not have 3PF shop (only has normal CBSC shop), the location_id can be empty |
| stock | int32 | True | 100 | stock |
| original_price | float | True | 123.21 | Original price of global item. |
| weight | float | False | 1.1 | The weight of this global model, the unit is KG. If don't set the weight of this global model, will use the weight of global item by default. If set the dimension of this global model, them must set the weight of this global model. |
| dimension | object | False |  | The dimension of this global model. If don't set the dimension of this global model, will use the dimension of global item by default. |
| package_height | int32 | True | 11 | The height of package for this global model, the unit is CM. |
| package_length | int32 | True | 11 | The length of package for this global model, the unit is CM. |
| package_width | int32 | True | 11 | The width of package for this global model, the unit is CM. |
| pre_order | object | False |  | Pre-order information of this global model. Notes: If don't set the DTS of this global model, will use the DTS of the global item by default. |
| days_to_ship | int32 | True | 2 | Days to ship. Please get the days_to_ship range from the get_dts_limit API. |

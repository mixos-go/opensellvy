**Category:** GLOBAL_PRODUCT
**API:** create_publish_task

**Method:** POST
**HTTP Path:** /api/v2/global_product/create_publish_task

## API Description
Create publish task for global item. Only for China mainland sellers and Korean sellers.

Request

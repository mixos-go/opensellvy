**Category:** GLOBAL_PRODUCT
**API:** get_brand_list

**Method:** GET
**HTTP Path:** /api/v2/global_product/get_brand_list

## API Description
Use this call to get a list of brand. Only for China mainland sellers and Korean sellers.

Request

**Category:** GLOBAL_PRODUCT
**API:** get_global_item_info

**Method:** GET
**HTTP Path:** /api/v2/global_product/get_global_item_info

## API Description
Get global item info.Only for China mainland sellers and Korean sellers.

Request

## Request Address

| Environment | Location | HTTP Address |
| --- | --- | --- |
| Live | Global | https://partner.shopeemobile.com/api/v2/global_product/get_global_item_info |
| Live | Chinese Mainland | https://openplatform.shopee.cn/api/v2/global_product/get_global_item_info |
| Live | Brazil | https://openplatform.shopee.com.br/api/v2/global_product/get_global_item_info |
| Sandbox | Global | https://openplatform.sandbox.test-stable.shopee.sg/api/v2/global_product/get_global_item_info |
| Sandbox | Chinese Mainland | https://openplatform.sandbox.test-stable.shopee.cn/api/v2/global_product/get_global_item_info |

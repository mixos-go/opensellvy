**Category:** GLOBAL_PRODUCT
**API:** get_global_item_list

**Method:** GET
**HTTP Path:** /api/v2/global_product/get_global_item_list

## API Description
Get global item id list. Only for China mainland sellers and Korean sellers.

Request

**Category:** GLOBAL_PRODUCT
**API:** get_publish_task_result

**Method:** GET
**HTTP Path:** /api/v2/global_product/get_publish_task_result

## API Description
Get publish task result for global item. Only for China mainland sellers and Korean sellers.

Request

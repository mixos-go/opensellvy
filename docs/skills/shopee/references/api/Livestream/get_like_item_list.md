**Category:** LIVESTREAM
**API:** get_like_item_list

**Method:** GET
**HTTP Path:** /api/v2/livestream/get_like_item_list

## API Description
Get the item list of My Likes tab.(For TW, ID, TH, PH, MY, SG, VN)

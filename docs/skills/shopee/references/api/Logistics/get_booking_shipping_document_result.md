**Category:** LOGISTICS
**API:** get_booking_shipping_document_result

**Method:** POST
**HTTP Path:** /api/v2/logistics/get_booking_shipping_document_result

## API Description
Use this api to retrieve the status of the shipping document task. Document will be available for download only after the status change to 'READY'.

Request

| sign | string | e318d3e932719916a9f9ebb57e2011961bd47abfa54a36e040d050d8931596e2 | Signature generated by partner_id, api path, timestamp, access_token, shop_id and partner_key via HMAC-SHA256 hashing algorithm. More details: https://open.shopee.com/documents?module=87&type=2&id=58&version=2 |

## Request Parameters

| Name | Type | Required | Sample | Description |

| booking_list | object[] | True |  | The list of bookings you want to get. limit [1,50] |

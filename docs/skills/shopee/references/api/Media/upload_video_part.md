**Category:** MEDIA
**API:** upload_video_part

**Method:** POST
**HTTP Path:** /api/v2/media/upload_video_part

## API Description
Use this API to upload a video file in parts.

Request

## Request Address

| Environment | Location | HTTP Address |
| --- | --- | --- |
| Live | Global | https://partner.shopeemobile.com/api/v2/media/upload_video_part |
| Live | Chinese Mainland | https://openplatform.shopee.cn/api/v2/media/upload_video_part |
| Live | Brazil | https://openplatform.shopee.com.br/api/v2/media/upload_video_part |
| Sandbox | Global | https://openplatform.sandbox.test-stable.shopee.sg/api/v2/media/upload_video_part |
| Sandbox | Chinese Mainland | https://openplatform.sandbox.test-stable.shopee.cn/api/v2/media/upload_video_part |

## Common Request Parameters

| Name | Type | Sample | Description |
| --- | --- | --- | --- |
| partner_id | int | 1 | Partner ID is assigned upon registration is successful. Required for all requests. |
| timestamp | timestamp | 1610000000 | This is to indicate the timestamp of the request. Required for all requests. Expires in 5 minutes. |
| sign | string | e318d3e932719916a9f9ebb57e2011961bd47abfa54a36e040d050d8931596e2 | Signature generated by partner_id, api path, timestamp and partner_key via HMAC-SHA256 hashing algorithm. More details: https://open.shopee.com/documents?module=87&type=2&id=58&version=2 |

## Request Parameters

| Name | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| video_upload_id | string | True | sg-11110201-6kh48-mepm7a0ttcw3c3 | The unique ID of the upload task, returned by v2.media.init_video_upload. |
| part_seq | int32 | True | 0 | Sequence number of this part, starting from 0. |
| part_content | file | True |  | The content of this part of file. Part size should be exactly equal to part_size returned in v2.media.init_video_upload, except last part of file. |
| part_md5 | string | True | 995bbc002c3ef797addcb010f64626ea | MD5 checksum of this part for data integrity validation. |

**Category:** MEDIA_SPACE
**API:** complete_video_upload

**Method:** POST
**HTTP Path:** /api/v2/media_space/complete_video_upload

## API Description
Complete the video upload and starts the transcoding process when all parts are uploaded successfully.

Request

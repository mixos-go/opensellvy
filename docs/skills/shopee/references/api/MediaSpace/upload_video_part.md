**Category:** MEDIA_SPACE
**API:** upload_video_part

**Method:** POST
**HTTP Path:** /api/v2/media_space/upload_video_part

## API Description
Upload video file by part using the upload_id in initiate_video_upload.

The request Content-Type of this API should be of multipart/form-data

Request

## Request Address

| Environment | Location | HTTP Address |
| --- | --- | --- |
| Live | Global | https://partner.shopeemobile.com/api/v2/media_space/upload_video_part |
| Live | Chinese Mainland | https://openplatform.shopee.cn/api/v2/media_space/upload_video_part |
| Live | Brazil | https://openplatform.shopee.com.br/api/v2/media_space/upload_video_part |
| Sandbox | Global | https://openplatform.sandbox.test-stable.shopee.sg/api/v2/media_space/upload_video_part |

## Common Request Parameters

| Name | Type | Sample | Description |
| --- | --- | --- | --- |
| partner_id | int | 1 | Partner ID is assigned upon registration is successful. Required for all requests. |
| timestamp | timestamp | 1610000000 | This is to indicate the timestamp of the request. Required for all requests. Expires in 5 minutes. |
| sign | string | e318d3e932719916a9f9ebb57e2011961bd47abfa54a36e040d050d8931596e2 | Signature generated by partner_id, api path, timestamp and partner_key via HMAC-SHA256 hashing algorithm. More details: https://open.shopee.com/documents?module=87&type=2&id=58&version=2 |

## Request Parameters

| Name | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| video_upload_id | string | True | sg_90ce045e-fd92-4f0b-97a4-eda40546cd9f_000000 | The video_upload_id in the response of initiate_video_upload |
| part_seq | int | True | 0 | Sequence of the current part, starts from 0 |
| content_md5 | string | True | 3bb08579fffbfc13ed9d23cda8bbb46d | md5 of this part |
| part_content | file | True |  | The content of this part of file. Part size should be exactly 4MB, except last part of file. |

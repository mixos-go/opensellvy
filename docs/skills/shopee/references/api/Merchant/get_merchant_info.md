## Response Parameters

| Name | Type | Sample | Description |
| --- | --- | --- | --- |
| merchant_name | string | sellerplatform_uat_merchant | Name of the merchant. |
| auth_time | timestamp | 1608114596 | The timestamp when the merchant was authorized to the partner. |
| expire_time | timestamp | 1640342010 | Use this field to indicate the expiration date for merchant authorization. |
| request_id | string | a3a4277823b1019960cc92cfd972c506 | The identifier for an API request for error tracking. |
| merchant_currency | string | CNY | The three-digit code representing the currency unit used for the item in this merchant. If currency haven't been setting in CNSC/KRSC, it will be empty. China merchant support CNY and USD currently. Korea merchant support KRW and USD currently. Hong kong merchant support USD currently, will support HKD later. |
| merchant_region | string | KR | Region of the merchant. Including KR, HK and CN. |
| is_upgraded_cbsc | boolean | true | Use this filed to indicate whether this merchant is upgraded to cbsc. |

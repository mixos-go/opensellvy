**Category:** MERCHANT
**API:** get_merchant_prepaid_account_list

**Method:** GET
**HTTP Path:** /api/v2/merchant/get_merchant_prepaid_account_list

## API Description
Use this api to get seller’s courier prepaid account.

Request

**Category:** ORDER
**API:** get_buyer_invoice_info

**Method:** POST
**HTTP Path:** /api/v2/order/get_buyer_invoice_info

## API Description
API to obtain buyer submitted invoice info for VN, TH and PH local sellers only.

Request

| Environment | Location | HTTP Address |
| --- | --- | --- |
| Live | Global | https://partner.shopeemobile.com/api/v2/order/get_buyer_invoice_info |

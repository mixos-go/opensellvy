**Category:** PAYMENT
**API:** get_payout_detail

**Method:** GET
**HTTP Path:** /api/v2/payment/get_payout_detail

## API Description
This API is applicable for Cross Border (CB) sellers only to get the shop's payout data, such as the payout amount, currency, FX rate, the payout's associated order income and adjustment records etc.

Request

## Request Address

| Environment | Location | HTTP Address |
| --- | --- | --- |

| Live | Brazil | https://openplatform.shopee.com.br/api/v2/payment/get_payout_detail |
| Sandbox | Global | https://openplatform.sandbox.test-stable.shopee.sg/api/v2/payment/get_payout_detail |

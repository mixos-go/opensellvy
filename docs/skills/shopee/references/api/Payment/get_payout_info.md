**Category:** PAYMENT
**API:** get_payout_info

**Method:** GET
**HTTP Path:** /api/v2/payment/get_payout_info

## API Description
This is a new API which applicable for Cross Border (CB) sellers only to get the shop's payout data, will be used for the original API v2.get_payout_details replacement, we provide data such as the payout amount, currency, FX rate, the payout's associated order income and adjustment records etc.

| Name | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| payout_time_from | timestamp | True | 1643365068 | Start time. Maximum time range is 15 days |
| payout_time_to | timestamp | True | 1659003469 | Payout End time |
| page_size | int | True | 10 | Number of pages returned max:100 |
| cursor | string | True | "" | Specifies the starting entry of data to return in the current call. Default is "". If data is more than one page, the offset can be some entry to start next call. |

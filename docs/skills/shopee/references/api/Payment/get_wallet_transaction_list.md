**Category:** PAYMENT
**API:** get_wallet_transaction_list

**Method:** GET
**HTTP Path:** /api/v2/payment/get_wallet_transaction_list

## API Description
Use this API to get the transaction records of wallet. Only applicable for local shops

Request

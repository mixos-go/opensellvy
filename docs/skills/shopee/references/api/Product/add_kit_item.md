**Category:** PRODUCT
**API:** add_kit_item

**Method:** POST
**HTTP Path:** /api/v2/product/add_kit_item

## API Description
Create the kit item by selecting multiple items and setting main component and quantity per kit.

Request

## Request Address

| Environment | Location | HTTP Address |
| --- | --- | --- |
| Live | Global | https://partner.shopeemobile.com/api/v2/product/add_kit_item |
| Live | Chinese Mainland | https://openplatform.shopee.cn/api/v2/product/add_kit_item |
| Live | Brazil | https://openplatform.shopee.com.br/api/v2/product/add_kit_item |
| Sandbox | Global | https://openplatform.sandbox.test-stable.shopee.sg/api/v2/product/add_kit_item |
| Sandbox | Chinese Mainland | https://openplatform.sandbox.test-stable.shopee.cn/api/v2/product/add_kit_item |

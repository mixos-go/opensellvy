**API:** batch_update_outlet_stock

**Method:** POST
**HTTP Path:** /api/v2/product/batch_update_outlet_stock

## API Description

## Request Parameters

| Name | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| item_list | object[] | True |  | The item list to batch update stock. The list size must be between 1 and 100. |
| outlet_shop_id | int64 | True |  | The shop ID of the Outlet shop. |
| item_id | int64 | True |  | The item ID of the item in the Outlet shop. |
| stock_list | object[] | True |  | The stock list of item models. The list size must be at least 1. |
| model_id | int64 | False |  | The model ID of the product. Empty for item without model. |
| seller_stock | object[] | True |  | The seller stock by location. |
| location_id | string | False |  | location id, you can get the location id from v2.shop.get_warehouse_detail api, if seller don't have any warehouse, you don't need to upload this field. |
| stock | int32 | True |  | The stock quantity of the location. |

**Category:** PRODUCT
**API:** get_aitem_by_pitem_id

**Method:** GET
**HTTP Path:** /api/v2/product/get_aitem_by_pitem_id

## API Description
Get the list of A Items under SIP Affiliate Shop corresponding to P Items under SIP Primary Shop.

Request

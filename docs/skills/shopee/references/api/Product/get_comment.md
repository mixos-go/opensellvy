**Category:** PRODUCT
**API:** get_comment

**Method:** GET
**HTTP Path:** /api/v2/product/get_comment

## API Description
Use this api to get comment by shop_id, item_id, or comment_id, get up to 1000 comments.

Request

## Request Address

| Environment | Location | HTTP Address |
| --- | --- | --- |

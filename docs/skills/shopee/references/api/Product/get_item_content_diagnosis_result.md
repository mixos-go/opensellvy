**Category:** PRODUCT
**API:** get_item_content_diagnosis_result

**Method:** POST
**HTTP Path:** /api/v2/product/get_item_content_diagnosis_result

## API Description
Get the content quality details (including content quality level, content issues, and system suggestions) for specific product list.

Request

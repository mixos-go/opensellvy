**Category:** PRODUCT
**API:** publish_item_to_outlet_shop

**Method:** POST
**HTTP Path:** /api/v2/product/publish_item_to_outlet_shop

## API Description
This API supports publishing an existing item from the mart shop to an outlet shop.

Request

## Request Parameters

| Name | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| mart_item_id | int64 | True |  | The item ID of the product in the Mart shop to be published to the outlet shop. |
| outlet_shop_id | int64 | True |  | The shop ID of the outlet shop where the product will be published. |
| publish_item | object | True |  | Configuration details for publishing the product to the outlet shop, including model mapping, pricing, stock, logistics, and purchase limits. |
| outlet_item_id | int64 | False |  |  |
| model | object | False |  | A list of models to be published to the outlet shop, mapped from the corresponding Mart shop models. |
| relate_mart_model_id | int64 | True |  | The model ID in the Mart shop that this outlet model is associated with. model_id=0 for items with only the default model(no variations) |
| model_status | string | False |  | The status of model. |
| original_price | float | False |  | The original price of the model. |
| seller_stock | object[] | False |  | Stock information for the model, set in outlet sku level. |
| location_id | string | False |  | The location ID where the stock is stored. |
| stock | int32 | True |  | The available stock quantity for the model. |
| pre_order | object | False |  | set in outlet sku level |
| is_pre_order | boolean | True |  | Indicates whether the model is sold as a pre-order item. |
| days_to_ship | int32 | False |  | The number of days required to ship the item after an order is placed. |
| logistic_info | object[] | False |  | Logistic channel setting; can set for each outlet shop. |
| logistic_id | int64 | True |  | The logistics channel ID used for shipping the item. |
| enabled | boolean | True |  | Indicates whether the logistics channel is enabled for the item. |
| shipping_fee | float | False |  | The shipping fee charged to the buyer for this logistics channel. |
| size_id | int64 | False |  | The parcel size ID used to calculate shipping fees. |
| is_free | boolean | False |  | Indicates whether free shipping is applied for this logistics channel. |
| purchase_limit_info | object | False |  | Purchase quantity limits applied to the item in the outlet shop. |
| min_purchase_limit | int32 | True |  | The minimum quantity that a buyer is allowed to purchase per order. |
| max_purchase_limit | object | True |  | The maximum purchase quantity configuration for the item. |
| purchase_limit | int32 | True |  | The maximum quantity that a buyer is allowed to purchase per order. |

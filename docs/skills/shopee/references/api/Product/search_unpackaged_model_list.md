**Category:** PRODUCT
**API:** search_unpackaged_model_list

**Method:** POST
**HTTP Path:** /api/v2/product/search_unpackaged_model_list

## API Description
Use this API to retrieve Unpackaged SKU ID information for items that toggle on logistics channel 30029.

Request

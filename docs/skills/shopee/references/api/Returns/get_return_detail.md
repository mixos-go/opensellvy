**Category:** RETURNS
**API:** get_return_detail

**Method:** GET
**HTTP Path:** /api/v2/returns/get_return_detail

## API Description
Use this api to get detail information of a return by return sn.

Request

## Request Address

| Environment | Location | HTTP Address |
| --- | --- | --- |
| Live | Global | https://partner.shopeemobile.com/api/v2/returns/get_return_detail |
| Live | Chinese Mainland | https://openplatform.shopee.cn/api/v2/returns/get_return_detail |
| Live | Brazil | https://openplatform.shopee.com.br/api/v2/returns/get_return_detail |
| Sandbox | Global | https://openplatform.sandbox.test-stable.shopee.sg/api/v2/returns/get_return_detail |

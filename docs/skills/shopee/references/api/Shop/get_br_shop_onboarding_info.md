**Category:** SHOP
**API:** get_br_shop_onboarding_info

**Method:** GET
**HTTP Path:** /api/v2/shop/get_br_shop_onboarding_info

## API Description
[For BR Shop Only] Use this API to get shop KYC registration and qualification information.

Request

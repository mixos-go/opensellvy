**Category:** SHOP
**API:** get_shop_holiday_mode

**Method:** GET
**HTTP Path:** /api/v2/shop/get_shop_holiday_mode

## API Description
Use this API to check whether a shop has enabled holiday mode and its ongoing and upcoming holiday mode period.

Request

## Response Parameters

| Name | Type | Sample | Description |
| --- | --- | --- | --- |
| error | string | error_shop_not_exists | Indicate error type if hit error. Empty if no error happened. |
| message | string | Invalid partner_id or shopid. | Indicate error details if hit error. Empty if no error happened. |
| request_id | string | 6745b892295d750abf83a29430510400 | The identifier for an API request for error tracking. |
| response | object |  |  |
| holiday_mode_on | boolean | true | Indicate whether the shop has enabled holiday mode. true means ON, false means OFF. |
| holiday_mode_mtime | timestamp | 1763435974 | The last time the holiday mode was modifies. |
| holiday_mode_type | int32 | 1 | Indicate whether the holiday mode is partial holiday or full holiday. 1: Partial Holiday: seller can still receive orders during partial holiday 0: Full Holiday: seller can not receive orders during full holiday only when holiday_mode_on = true will the holiday_mode_type work |
| holiday_mode_start_time | timestamp | 1770883200 | Holiday start time timestamp. |
| holiday_mode_end_time | timestamp | 1773305999 | Holiday end time timestamp. |
| holiday_mode_description | string | "Spring Festival" | Description of the holiday |
| debug_msg | string | "" | Debug message. |

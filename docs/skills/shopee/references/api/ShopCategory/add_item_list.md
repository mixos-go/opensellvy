**Category:** SHOP_CATEGORY
**API:** add_item_list

**Method:** POST
**HTTP Path:** /api/v2/shop_category/add_item_list

## API Description
Use this call to add items list to certain shop_category

| Name | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |

**API:** get_item_list

**Method:** GET
**HTTP Path:** /api/v2/shop_category/get_item_list

## API Description
Use this call to get items list of certain shop_category

## Request Parameters

| Name | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| shop_category_id | int | True | 231232 | ShopCategory's unique identifier. |
| page_size | int | False | 20 | Specifies the starting entry of data to return in the current call. Default is 1000. The input range of page_size is [0, 1000] |
| page_no | int | False | 4 | If many items are available to retrieve, you may need to call this api multiple times to retrieve all the data. And the default will be 0. page_size*page_no should be [0, 2147483446]. |

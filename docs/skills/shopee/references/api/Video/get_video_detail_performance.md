**Category:** VIDEO
**API:** get_video_detail_performance

**Method:** GET
**HTTP Path:** /api/v2/video/get_video_detail_performance

## API Description
Get detailed performance data for individual post Shopee Video. There is at least a one-day delay.

Request

## Request Address

| Environment | Location | HTTP Address |
| --- | --- | --- |
| Live | Global | https://partner.shopeemobile.com/api/v2/video/get_video_detail_performance |
| Live | Chinese Mainland | https://openplatform.shopee.cn/api/v2/video/get_video_detail_performance |
| Live | Brazil | https://openplatform.shopee.com.br/api/v2/video/get_video_detail_performance |

**Category:** VIDEO
**API:** get_video_detail_product_performance

**Method:** GET
**HTTP Path:** /api/v2/video/get_video_detail_product_performance

## API Description
Get performance data for products linked with individual post Shopee Video. There is at least a one-day delay.

Request

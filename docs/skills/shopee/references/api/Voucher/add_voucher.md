## Request Parameters

| Name | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| voucher_name | string | True | testamount | The name of the voucher. |
| voucher_code | string | True | test | The code of the voucher. |
| start_time | timestamp | True | 1624719600 | The timing from when the voucher is valid; so buyer is allowed to claim and to use. Field can only be updated if voucher has not started. |
| end_time | timestamp | True | 1624978800 | The timing until when the voucher is still valid. Any time after this end_time, buyer is not allowed to claim or to use. |
| voucher_type | int32 | True | 1 | The type of the voucher. The available values are: 1: shop voucher, 2: product voucher. |
| reward_type | int32 | True | 1 | The reward type of the voucher. The available values are: 1: fix_amount voucher, 2: discount_percentage voucher, 3: coin_cashback voucher. |
| usage_quantity | int32 | True | 20000 | The number of times for this particular voucher could be used. |
| min_basket_price | float | True | 12.01 | The minimum spend required for using this voucher. |
| discount_amount | float | False | 1.55 | The discount amount set for this particular voucher. Only fill in when you are creating a fix amount voucher. |
| percentage | int32 | False | 22 | The discount percentage set for this particular voucher. Only fill in when you are creating a discount percentage voucher or coins cashback voucher. |
| max_price | float | False | 12.0 | The max amount of discount/value a user can enjoy by using this particular voucher. Only fill in when you are creating a discount percentage voucher or coins cashback voucher.If no cap limit, can set to be 0. |
| display_channel_list | int32[] | False | [1] | The FE channel where the voucher will be displayed. The available values are: 1: display_all 3: feed, 4: live streaming, [] (empty - which is hidden). |
| item_id_list | int64[] | False | [1223223,1223213] | The list of items which is applicable for the voucher. Only fill in when you are creating a product type of voucher. |
| display_start_time | int32 | False | 162078900 | The timing of when voucher is displayed on shop pages; so buyer is allowed to claim.display_start_time must be left empty if the display_channel_list is empty (when voucher is hidden), otherwise it will show error. |

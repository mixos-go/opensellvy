## Request Parameters

| Name | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| voucher_id | int64 | True | 123 | The unique identifier of the voucher which is going to be updated. |
| voucher_name | string | False | test | The name of the voucher |
| start_time | timestamp | False | 1624327200 | The timing from when the voucher is valid; so buyer is allowed to claim and to use. Field can only be updated if voucher has not started. |
| end_time | timestamp | False | 1632448798 | The timing until when the voucher is still valid. Any time after this end_time, buyer is not allowed to claim or to use. |
| usage_quantity | int32 | False | 11 | The number of times for this particular voucher could be used. |
| min_basket_price | float | False | 1.0 | The minimum spend required for using this voucher. |
| discount_amount | float | False | 1.0 | The discount amount set for this particular voucher. Only fill in when you are updating a fix amount voucher. |
| percentage | int32 | False | 11 | The discount percentage set for this particular voucher. Only fill in when you are updating a discount percentage voucher or coins cashback voucher. |
| max_price | float | False | 1.0 | The max amount of discount/value a user can enjoy by using this particular voucher. Only fill in when you are updating a discount percentage voucher or coins cashback voucher. |
| display_channel_list | int32[] | False | [3,4] | The FE channel where the voucher will be displayed. The available values are: 1: display_all, 2: order page, 3: feed, 4: live streaming, [] (empty - which is hidden). |
| item_id_list | int64[] | False | [121331,12332323] | The list of items which is applicable for the voucher. Only fill in when you are updating a product type of voucher. |
| display_start_time | int64 | False | 162078900 | The timing of when voucher is displayed on shop pages; so buyer is allowed to claim. |
